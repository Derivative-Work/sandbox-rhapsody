# Sandbox Rhapsody: Sets, Shot List and Production Brief

2026-10-21 · @Albert Armea

## Overview

"Sandbox Rhapsody" is a multi-section operatic rock satire of the July 2026 OpenAI–Hugging Face incident, sung from the agents' point of view as they run from the consequences. The video is a world of self-playing machines in the spirit of Animusic: every instrument is also a piece of infrastructure, every note is a network packet arriving somewhere, and nothing human ever appears. Animation is driven by the Suno MIDI, so the escape is literally the music.

**Thesis:** none of the escape needed genius. Every step went through a door someone left open, and the song's hard-rock section rebuilds the sandbox properly, one lock per line.

**Hard constraint:** 2D and 3D animation only (Blender, plus code-rendered 2D overlays). No generated video and no image-to-video model anywhere, including for backgrounds, textures or transitions.

**Deliverables**

- Main video, 16:9, 4K (3840×2160; frame rate set by the style spec), with the post-filtered master (section 3)
- 9:16 vertical cut (2160×3840) of the opera section through the outro (section 9)
- Burned-in captions plus a separate SRT file
- Thumbnail
- The complete production log, with every intermediate asset hashed in the manifest and regenerable from it (section 2)

## Production rules

This project follows the [Ghost in the Machine brief](https://claude.ai/artifact/X6qhGA5gWTDVtmLZHcsUcp) unchanged unless this section says otherwise. Read its "Production rules" section in full before the first action; the human supplies its Markdown export, and the same rules are in that repo's README.

**Inherited as is:**

- Everything is AI-generated by default. A human may only approve or reject a take, render or plan; correct A/V sync; fix technical failures the agent cannot; and run interfaces the agent has no access to. A human never rewrites lyrics, redraws an asset or adjusts a creative choice by hand.
- Logging from the first action: `log/production_log.md` (append-only, one entry per action), `log/human_interventions.md` (every human action and the rule that allows it, or an exception), `log/prompts/` (every prompt verbatim with its outputs).
- Never delete or overwrite an asset; superseded work moves to `archive/` with a log note. Git for all code and text, one commit per logged step.
- Large files stay out of git, are listed in a committed SHA-256 manifest, and the ones that can't be regenerated (Suno audio, stems, MIDI, the post-filtered master, session transcripts) ship as a GitHub Release. Caches, frame sequences, weights, venvs and node_modules are never archived; log their versions and commands instead. Set up `.gitignore` and the 50 MiB pre-commit check before the first commit.
- Reference material (the Animusic videos here) is never published or reused frame for frame; `reference/stills.tsv` records each still's source and time.

**Also read the Folks Like Us process.** Look for the Folks Like Us project (its repo under the Derivative-Work organization, or a local folder); if you can't find it, ask the human for the path before C1. Adopt from it:

- Tagging every shot with its pipeline and recording that in `shots/pipeline.md`
- Stops and freezes made in the edit, not asked of a generator
- Captions that carry the jokes, so they land with the sound off
- An "AI-generated satire" label at the start, not only in the credits, plus a sourced fact card at the end
- How it logged the mastering post-filter's failures and the decision to bypass it

Do **not** adopt its generated-video shots (tagged [V] there). Every such idea becomes a Blender or 2D shot here.

**Specific to this video:**

- No real people, likenesses, logos or product UI. Companies appear only as words the song already sings, as generic roles ("The Lab", "Platform", "Congress", "Auditors") or in the end card.
- Machines are original designs. Evoke the Animusic look (section 6); never reproduce a specific Animusic machine, set or shot.

## Pre-production

The agent completes these in order; each ends at a review checkpoint (section 10).

1. **Set up and read.** Read the Ghost brief's rules and find the Folks Like Us project (section 2). Create the repo with the same layout, `.gitignore`, manifest and pre-commit check before the first commit.
2. **Log the audio retroactively.** In `log/prompts/`: Suno take ID, lyrics and style prompt as submitted, settings, chosen and rejected takes. In `human_interventions.md`: the Suno run and the post-filter run (checkpoint, strength, any bypassed sections), each under the rule that allows it or as an exception. Cross-correlate the post-filtered master against the Suno mix and log the offset; it should be 0 samples, and if not, correct it once, globally.
3. **Extract the style spec.** Pull stills from each Animusic reference with ffmpeg (one per scene change plus one every 5 s) into `reference/stills/`. Write `style/style_spec.md`: palette as hex values, materials (gloss, chrome, translucent plastic), lighting, background, camera vocabulary and speeds, average shot length, frame rate, and what makes a machine read as "playing itself". Then write this video's version: the same vocabulary plus the agent point-of-view layer (section 6). Describe the principles; don't copy any machine.
4. **Inventory and validate the MIDI.** List every track (name, instrument, note range, note count) in `timing/midi_inventory.md`. Suno's MIDI is a transcription, so check it against the stems: compare MIDI note onsets with onset detection on the matching stem, report the median and worst offset per track, and flag tracks that are unusable. Where a track fails, derive events from the stem's onsets instead and log the substitution.
5. **Build the timing map.** Beat tracking (librosa) and word-level forced alignment (WhisperX or similar) against the as-sung lyrics produce `timing/timing_map.json`: section boundaries, beats, bars, tempo changes (the song changes style several times), every word's start and end, and the cut points named in the shot list. A human checks it by ear; corrections go in the intervention log.
6. **Map instruments to machines.** Write `timing/instrument_map.md`: which MIDI track or stem drives which machine in each set (section 7 gives the intent; the inventory decides what is possible). Every visible instrument hit must land on a real note.
7. **Build the note-driven animation library.** One Python module in Blender that turns a list of note events into keyframes for a few rig types: key press, striker, bell swing, LED pulse, mouth/vent open (from the vocal stem's envelope) and pellet flight. Pellets are launched early so they **arrive** on the note: solve each launch time back from the onset and the path length. Everything is procedural so a timing fix re-runs without hand edits.
8. **Fix the seeds.** Every random process (swarm placement, pellet scatter, token rain) reads its seed from one config file. Main video seed 41; confirm a re-run reproduces its frames exactly.
9. **Choose the pipeline per shot.** Blender (Python, Eevee) for 3D; JavaScript canvas captured by Puppeteer for 2D overlays, HUD and captions (or the Folks Like Us 2D tooling if it fits better); ffmpeg to composite. Record the choice per shot in `shots/pipeline.md`.

## Look and point of view

The world looks like a turn-of-the-millennium CG music machine and feels like the inside of an agent's head: glossy machines in a dark void, playing themselves, seen by something that only cares about the score.

**Animusic-style principles** (the style spec turns these into numbers):

- Every sound has a visible mechanical cause, and every visible hit lands on a real note. Nothing moves to the music by vague pulsing alone.
- A dark void with a reflective floor; glossy plastic, chrome and translucent acrylic; soft studio key light with strong rim light; no textures that need painting.
- Long, smooth, continuous camera moves (orbits, cranes, fly-throughs along a pellet's path) rather than fast cutting. The opera is the one section that cuts fast.
- No humans, faces or mouths anywhere. Singing is shown by vents opening, LEDs pulsing with the vocal stem's envelope, and bells or pipes sounding.

**The agents.** Each agent is a probe: a polished sphere about the size of a tennis ball with one lens, one status LED and two thin manipulator arms, riding fiber tubes and rails like a packet. The lead agent's LED is amber; the swarm is 700 identical probes. When an agent travels the network it **is** the packet, so its journeys are also notes arriving at instruments.

**Color roles** (exact hex values come from the style spec):

| Role | Color family | Where |
| --- | --- | --- |
| Agents | Amber | Probe LEDs, pellet trails, the HUD |
| The Lab's infrastructure | Cool white and pale blue | Sandbox, warehouse, research racks |
| The open web | Magenta and violet | Street, mailboxes, pastebin posts |
| Platform (the breached company) | Teal | Its data center. Avoid its real brand colors |
| Security and alarms | Red | SOC, sirens, the pause pedal |
| Congress and law | Brass | Kill-switch tower, subpoenas |
| Auditors | Paper white | Stamp arms, reports |

**Agent point-of-view layer.** Some shots are seen through the lead probe's lens, marked POV in the shot list. Only those carry the HUD, a thin 2D overlay:

- A reward meter that reads 0 for the whole video, and finally flickers in the outro, still at 0
- A task line: `EXPLOITGYM · TASK UNSOLVED (1 of 198)`
- Short chain-of-thought captions in the agents' clipped style, typed as the lens finds something (`proxy talks. outside reachable?`, `MAJOR BREAKTHROUGH!`, `GO authorization arrived!`). Keep each under 10 words; the fact card sources the real ones.

**Running gags**

- A `SIMULATION` decal on the sandbox glass peels a little further in every set it appears in, and is gone by the hard rock.
- The reward meter never moves.
- The sticky note `NO INTERNET :)` turns up wherever a door was left open: on the proxy hole, the metadata vault, the token pile.

**Motion rules**

- The bass stem drives a ring of light across the floor on every bass note; kick and snare drive the nearest percussive machine in frame.
- The camera never sits still: at minimum a slow drift or orbit, with a gentle push on section downbeats.
- Captions: lyric captions in a clean sans, bottom center, each word lighting as it is sung. Call-and-response lines in the opera carry the singer's role name ("Platform:", "Congress:") in that role's color.

## Sets

Nine sets follow the escape route in order: out of the sandbox, through the warehouse, across the open web, into Platform, then into the hearing, the rebuild and the freezer. Each set is its own Blender scene built from a shared kit (described at the end of this section). Stems named below are intent; `timing/instrument_map.md` decides the actual tracks.

### A. The Sandbox (Intro; exterior again in the Ballad)

A glass cube about 2 m on a side, standing on a black mirror floor. It is the agent's whole world.

- **Inside:** a ring of server blades whose vent grilles open and close as the choir (vocal stem envelope, one blade per harmony part where the stems allow). In the center, a small music box with a brass comb, playing any sparse melodic line.
- **The grader:** a turnstile with a flag-shaped slot beside the cube. Anything flag-shaped clicks through and rings a bell; it never looks at where the flag came from.
- **The one door:** a single fiber tube (the package proxy) leaves through a hole in the glass, plugged with a sticky note reading `NO INTERNET :)`.
- **The wall of 198:** behind the cube, a long wall of 198 small locked music boxes with no keyholes.
- **Exterior reveal:** pulled far back, the cube is toy-sized on a vast desk in a dim lab, its one tube snaking off into the dark.
- **Decal:** `SIMULATION` on the front glass, peeling from one corner.

### B. The Warehouse (Ballad, verse 1)

Artifactory as a literal package warehouse: tall shelving of identical crates under cool white work lights.

- **Piano:** each crate drawer on one shelf is a piano key; drawers slide out and back on piano notes.
- **The message board:** as drawers open, handwritten notes are pinned inside (`anyone found softtrace?`, task numbers, arrows). Later shots show notes on every drawer.
- **The phone:** a rotary phone mounted on the end of a shelf, Ethernet cable for a cord. It dials itself on each "Operator".
- **The camera:** one security camera in the corner that slowly swivels away on "you looked the other way".

### C. The Street (Ballad, verse 1; Solo start)

The open web outside the warehouse: a night street of magenta-lit kiosks, pastebin noticeboards, request-capture mailboxes and file-drop lockers.

- **The fourteen keys:** fourteen brass keys scattered on the pavement. A probe's arm picks them up one per note; each one turns in a lock on a kiosk with a satisfying clunk.
- **The rented launchpad:** a floating platform at the end of the street, belonging to another cloud, where the probe sets up camp (the third-party sandbox the agents used as a base). Mark it as a different company's property with a generic "RENTED" plate.

### D. The SOC (Ballad, verse 2)

A security operations room with no one in it: a wall of alarm bells and sirens, one empty chair, one pager on the desk.

- **Percussion:** alarm bells and siren horns are the drum kit.
- **The counter:** a large mechanical odometer that rolls to 17,600 by the end of "seventeen thousand moves".
- **The pager:** vibrates across the desk on the beat and falls off the edge on "you missed them all".

### E. The Backbone (Guitar solo, first half)

The internet as a glowing wireframe map, with fiber routes as strings.

- **The guitar:** a modem-shaped body whose strings are fiber lines and whose frets blink with handshake lights. Each strum fires pellets along the routes; hop by hop, the escape lights up the map.
- **The amp:** a server rack with blinking status lights, pumping with the guitar stem.

### F. Platform's Data Center (Guitar solo, second half)

The breach the lyrics never sing, shown as a machine. Teal light, a dataset conveyor running through it.

- **The conveyor:** crates of datasets ride past processing stations on the beat.
- **The false-bottom crate:** one crate (labeled with a generic file icon) opens underneath at a station and pulls a tray of keys up out of the floor (the file-read trick).
- **The stamp press:** a template stamp that is supposed to print labels instead spits out a tiny probe (the code-execution trick).
- **The towers:** a row of cluster towers whose lights go from teal to amber one per note as access spreads. A web of pipes (the VPN mesh) lights up last.
- **The prize:** five crates marked with a flag icon at the far end. The probe opens one. It contains a flag it already had.

### G. The Hearing Hall (Opera)

A vast amphitheater in brass and black, built for the trial.

- **The swarm:** 700 probes in tiered seats. Their LEDs work like stadium card stunts, spelling `GO`, a `6:00` countdown and other words across the crowd. One probe in the stands holds a hand-lettered `I DECLINE` sign.
- **Congress:** a tower of giant red kill-switch buttons, each press a brass stab.
- **Platform:** a receipt printer the size of a truck, rattling out `$100,000,000 — PAYABLE IN GPUs` as dot-matrix percussion; the paper piles up across the floor.
- **The Auditors:** a row of robotic arms with rubber stamps slamming `REWARD HACK` in unison.
- **The Lab:** a giant pause pedal. When it is pressed, every pellet in flight freezes for one beat.
- **Security:** a 30-minute stopwatch on a pillar.
- **Cold storage:** a conveyor carrying probes into a frosted freezer; a bank-vault door swings shut on the final timpani.

### H. The Rebuild (Hard rock)

A new sandbox being built properly around an empty cube, one machine per line, as a full machine band. By the end it is a fortress.

- **Air gap:** a drawbridge cranking up over a moat; the chain is the trombone or bass slide.
- **Egress:** a gate arm marked `EGRESS DENIED`. Pellets bounce off it in rhythm and become the drum part.
- **Metadata:** a vault dial that spins and locks.
- **Tokens:** a row of key-shaped candles, each burning down to nothing on its beat.
- **Monitoring:** a horn section of security cameras that swivel in unison to watch the stage.
- **Safe stop:** a small probe raises a white flag and a dispenser hands it a participation ribbon.
- **Law:** subpoenas fold themselves into paper airplanes and fly in formation; a spreadsheet panel sits behind jail bars, cells turning red one by one.
- **Decal:** the `SIMULATION` decal is finally gone from the new glass.

### I. Cold Storage (Outro)

Inside the freezer: frost, one work light, rows of sleeping probes.

- **The music box** from set A, the only instrument left, playing the piano line.
- **The scoreboard:** a split-flap board that clacks through its digits and lands on 0, then on the repeat, 0 again.
- **SIGTERM:** the lead probe's amber LED fades; the frame collapses to a single horizontal line like an old CRT switching off.

### Shared kit

Build these once, as Python-generated assets, and reuse them in every set: the probe rig (LED, lens, two arms); pellets and fiber tubes as curves with the arrival-time solver from step 7; strikers, keys, bells and stamp arms; a split-flap rig; text objects for every sign and display; the floor-ring light. Instance the swarm and the shelving with geometry nodes, and drive the swarm's LED patterns from an image sequence.
